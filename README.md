## 使用方式
1. 解壓縮 ZIP，把整個資料夾部署至 GitHub Pages 或靜態主機。
2. 本機可於此資料夾執行 `python -m http.server 8000`，以 `http://localhost:8000` 開啟。不要直接雙擊 HTML 測試 Service Worker。
3. 上線前備份原網站及玩家資料；請勿將本測試版直接覆蓋正式版本。
